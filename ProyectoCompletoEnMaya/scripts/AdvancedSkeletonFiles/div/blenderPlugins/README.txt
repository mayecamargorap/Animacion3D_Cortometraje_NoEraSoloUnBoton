AdvancedSkeleton Blender 1.0.1
From AdvancedSkeleton 6.901
Last Modified 30/08/2026

Install: Blender > Edit > Preferences > Get Extensions > Install from Disk, then select AdvancedSkeletonBlender-1.0.1.zip.

Use: Open the 3D View sidebar > AdvancedSkeleton, then Import FBX, choose Body JSON, and Build Rig.
